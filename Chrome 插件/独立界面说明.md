# 独立详细界面使用说明

## 🎉 新增功能

扩展现在包含两个界面：

### 1. **快速查看界面（弹窗）**
- 位置：点击扩展图标
- 特点：简洁快速，显示核心数据
- 功能：
  - 今天访问最多的网站
  - 全部网站统计
  - 简单图表
  - 快速清除数据

### 2. **详细统计界面（独立页面）** ⭐ 新增
- 位置：点击"打开详细页面"按钮 或 右键扩展图标 → 选项
- 特点：完整功能，深度分析
- 功能：
  - 📊 今天/本周/本月/全部 四个时间维度
  - 📈 统计卡片（总时长、网站数）
  - 📉 详细图表（更大更清晰）
  - 💾 数据导出（JSON格式）
  - 📥 数据导入（支持备份恢复）
  - 🗑️ 清除数据（今天/全部）

## 🚀 如何使用

### 方法一：从弹窗打开
1. 点击Chrome工具栏的扩展图标
2. 点击"打开详细页面"按钮
3. 详细界面将在新标签页打开

### 方法二：从右键菜单打开
1. 右键点击扩展图标
2. 选择"选项"
3. 详细界面将打开

### 方法三：直接访问
在地址栏输入（替换为您的扩展ID）：
```
chrome-extension://扩展ID/options.html
```

## 📊 界面说明

### 四个时间维度

#### 1️⃣ 今天
- 查看今天访问的所有网站
- 统计今天的总使用时长
- 显示访问网站数量

#### 2️⃣ 本周
- 本周（周日到周六）的所有数据
- 累计使用时长和网站数
- 适合周度总结

#### 3️⃣ 本月
- 本月的所有访问记录
- 月度使用分析
- 追踪长期使用习惯

#### 4️⃣ 全部
- 所有历史数据
- 长期使用统计
- 全面了解使用情况

### 统计数据卡片
每个时间维度都有两个统计卡片：
- **总访问时长**：显示该时间段的总时间
- **访问网站数**：显示访问的不同网站数量

### 详细网站列表
- 按使用时间排序
- 显示完整的域名
- 时间格式美观（秒/分钟/小时）
- 进度条可视化使用占比

### 图表可视化
- 更大的画布（350px高度）
- 显示前10个最常用网站
- 渐变条形图
- 清晰的时间标注

## 💾 数据管理

### 导出数据
1. 点击"导出数据"按钮
2. 自动下载JSON文件
3. 文件命名：`website-tracker-2025-10-28.json`
4. 可用于备份或分析

### 导入数据
1. 点击"导入数据"按钮
2. 选择之前导出的JSON文件
3. 数据立即导入并覆盖
4. 可用于恢复备份

### 清除数据

#### 清除今天
- 只删除今天的数据
- 保留历史记录
- 适合每天重置

#### 清除所有
- 删除所有历史数据
- 不可恢复
- 谨慎操作

3. **定期查看**：每天查看今天数据，养成习惯

## 🔧 技术细节

### 文件结构
```
options.html   - 独立界面HTML
options.css    - 独立界面样式
options.js     - 独立界面逻辑
```

### 数据获取
- **今天**：key 以 `_2025-10-28` 结尾的记录
- **本周**：本周一之后的所有记录
- **本月**：本月1日之后的所有记录
- **全部**：所有存储的记录

### 图表绘制
- 使用Canvas API
- 动态计算条形宽度
- 渐变填充效果
- 实时数据更新

## ⚠️ 注意事项

1. **数据格式**：导出的是Chrome存储的原始格式
2. **导入覆盖**：导入会覆盖现有所有数据
3. **清除不可逆**：清除后无法恢复，除非有备份
4. **浏览器兼容**：需要Chrome内核浏览器
