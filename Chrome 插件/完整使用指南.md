## 🚀 快速安装

### 步骤1：准备图标（可选）
```
方式A：打开 create_icons.html 生成图标
方式B：跳过此步骤，扩展也能正常使用
```

### 步骤2：加载扩展
```
1. 打开 Chrome 浏览器
2. 访问 chrome://extensions/
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 D:\code\Chrome 插件 文件夹
```

### 步骤3：开始使用
```
1. 点击扩展图标查看数据
2. 点击"打开详细页面"查看完整数据
3. 扩展会自动追踪访问时间
```

## 📊 数据格式

### 存储格式
```json
{
  "google.com_2025-10-28": 3600,
  "github.com_2025-10-28": 1800,
  "stackoverflow.com_2025-10-27": 7200
}
```

### 时间格式化
- < 60秒：`30秒`
- < 1小时：`45分钟30秒`
- ≥ 1小时：`2小时30分钟`

## 🔧 技术栈

- **Manifest V3** - 最新扩展标准
- **Service Worker** - 后台持久化
- **Chrome Storage API** - 本地数据存储
- **Chrome Tabs API** - 标签页监控
- **Canvas API** - 图表绘制
- **Vanilla JavaScript** - 纯JS实现
- **Responsive Design** - 响应式布局

## 🎯 核心功能实现

### 后台追踪
```javascript
// 域名提取
getDomain(url) → "google.com"

// 时间记录
saveTime(domain, duration)
// 存储为：google.com_2025-10-28 → 3600秒

// 自动保存（每30秒）
setInterval(() => saveTime(), 30000)
```

### 数据聚合
```javascript
// 今天数据
keys ending with "_2025-10-28"

// 本周数据
date >= this week's Monday

// 本月数据
date >= this month's 1st

// 全部数据
all keys
```

### 图表绘制
```javascript
Canvas API → 条形图
- 计算比例宽度
- 渐变填充
- 标签标注
```
