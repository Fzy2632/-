========================================
如何打开独立界面
========================================

方式1：从弹窗打开
  点击扩展图标 → 点击"打开详细页面"按钮

方式2：从右键菜单打开
  右键扩展图标 → 选择"选项"

方式3：直接访问
  chrome-extension://扩展ID/options.html

========================================
独立界面功能
========================================

🕐 时间维度
  - 今天：今天的数据
  - 本周：本周（周日-周六）的数据
  - 本月：本月的数据
  - 全部：所有历史数据

📊 统计卡片
  - 总访问时长
  - 访问网站数

📈 详细图表
  - Canvas绘制
  - 前10个最常用网站
  - 大尺寸显示（350px高度）

💾 数据管理
  - 导出：保存为JSON文件
  - 导入：从JSON文件恢复
  - 清除今天
  - 清除全部

========================================
数据存储位置
========================================

Chrome本地存储
位置：Chrome User Data → Local Storage
格式：域名_日期 → 秒数
示例：google.com_2025-10-28 → 3600

========================================
安装步骤
========================================

1. 打开 Chrome
2. 访问 chrome://extensions/
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 D:\code\Chrome 插件 文件夹
6. 完成！

图标可选（扩展能正常使用）
