# 网站时间追踪 Chrome 扩展

这是一个用于追踪您在各个网站上花费时间的Chrome浏览器扩展。

## 功能特点

- 📊 追踪您在每个网站上的停留时间
- 📈 显示今天访问时间最长的网站
- 📉 图表可视化展示使用情况
- 🗑️ 支持清除今天或所有数据
- 🎨 美观的现代化界面

## 安装步骤

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择此文件夹
5. 扩展程序安装完成

## 图标准备

由于图标文件较大，请按以下步骤准备图标：

### 方法一：使用在线工具生成
1. 访问 https://www.favicon-generator.org/ 或其他图标生成工具
2. 上传一个简单的时钟或统计图标
3. 下载16x16, 48x48, 128x128尺寸的图标
4. 将图标放入 `icons` 文件夹，命名为：
   - icon16.png
   - icon48.png
   - icon128.png

### 方法二：快速创建临时图标
您可以使用任何简单的图片作为临时图标，扩展程序的核心功能不受影响。

## 使用方法

1. 安装后，扩展会自动开始追踪您访问的网站
2. 点击扩展图标查看：
   - **今天**：今天访问时间最长的网站列表和图表
   - **全部**：所有网站的总使用时间
3. 使用清除按钮删除数据

## 技术栈

- Manifest V3
- Chrome Storage API
- Canvas API (用于图表绘制)
- Vanilla JavaScript

## 数据存储

所有数据存储在本地（Chrome存储），不会上传到任何服务器，保护您的隐私。

## 注意事项

- 扩展会忽略 chrome:// 和系统页面
- 数据每30秒自动保存一次
- 切换到新标签页时会自动更新追踪目标
